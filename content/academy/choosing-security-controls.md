## Understand the concept

A control has both an implementation category and a purpose. A badge reader is a technical mechanism at a physical boundary; an access policy is managerial. A control that blocks an action is preventive, while a log review that discovers it is detective. A backup becomes useful as a corrective capability during recovery. These labels describe how the control is used, not just the product name.

## Apply it to a realistic decision

A club file server has overly broad permissions. Reducing access prevents exposure; collecting access logs helps investigate it; a policy assigns ownership. Adding more logs alone does not reduce who can read the files. A compensating control should address the same risk when the preferred control cannot be implemented.

## Practice and explain

Choose one preventive, detective and corrective control for a shared lab laptop. State what evidence would demonstrate each works.

Write a short answer before checking the flashcard or quiz. Include the evidence you would collect, a likely failure case, and a limitation of your proposed control. Good security work makes assumptions visible and gives another person a way to verify the result.

## Check your understanding

How does a detective control differ from a preventive control?

**Expected reasoning:** Detection reveals activity after or during it; prevention stops or limits it before harm. The report discovers an event after it occurs. It does not itself prevent the change.
