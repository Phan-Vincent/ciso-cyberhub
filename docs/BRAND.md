# CyberHub brand

CyberHub is red and black. Light mode is red and black on warm paper; dark mode is red on black. The theme follows the visitor's system setting. There is no blue anywhere, including logos.

| File | Use |
|---|---|
| `cyberhub-core-on-dark.svg`, `cyberhub-core-on-light.svg` | The Core mark in the header and footer |
| `cyberhub-favicon.svg`, `cyberhub-app-icon.svg` | Browser and home-screen icons |
| `cyberhub-core-animated.svg`, `*-mono-*`, `*-wordmark-*` | Slides, print and social |

Type: IBM Plex Sans for headlines and body (headlines uppercase), IBM Plex Mono for labels and code. Signal red is `#ff3b30` on dark and `#d71e1e` on light.

CyberHub is an independent student project with no club or university affiliation for now. Do not add club logos or "powered by" lines without the owner's say-so.
